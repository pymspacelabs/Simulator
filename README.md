# 👨🏻‍🚀 Simulator - A space exploration interactive simulation tool

## 🚀 About
This project was built for the NASA Space Apps Challenge 2026. The Challenge was the `Build a Junior Astronaut Mission Trainer`, and for that, initially, it was implemented this Proof-of-Concept, consisting of a dataset with 240,000 samples (80,000 each for the ISS, the Moon, and Mars) and 32 features. It utilizes a Quad-Ensemble (Microsoft.ML.FastTree) model, calibrated using mass balance data from NASA’s ECLSS and eight public NASA APIs (DONKI, JPL Horizons, OSDR, TechPort #182369, TechTransfer, NTRS, InSight Weather, and TLE ISS), to simultaneously predict the $\text{CH}_4$ replenishment rate, mission duration (days of exploration), biological survival, and system reliability.  
This POC was build with a purpose to serve as an machine learning model basis to implement a Decision Card Game, for the final challenge goal.
